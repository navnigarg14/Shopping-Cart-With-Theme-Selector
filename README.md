# 🛍️ Shopping Cart with Theme Selector

A responsive shopping cart application built using **React.js, JavaScript, HTML, CSS, and Tailwind CSS**. This project combines shopping cart functionality with a customizable theme selector, offering three distinct visual experiences: **Dark, Light, and Neon**.

The goal of this project was to practise React development, build an interactive user interface, and explore dynamic theme customization.

## ✨ Features

### 🛒 Shopping Cart
- Interactive shopping cart interface.
- Add products to the cart.
- Manage cart items using the available controls.
- Dynamic user interface powered by React.js.

### 🎨 Theme Selector

Choose from three different themes to personalize the application's appearance.

| Theme | Description |
|---|---|
| 🌙 Dark Theme | A sleek, dark interface with contrasting elements. |
| ☀️ Light Theme | A clean, bright interface for a minimal look. |
| ⚡ Neon Theme | A vibrant interface featuring neon-inspired styling. |

### 💻 User Interface
- Component-based architecture using React.js.
- Utility-first styling with Tailwind CSS.
- Interactive UI elements.
- Reusable components for maintainable code.

## 🛠️ Tech Stack

- **HTML5** — Structuring the application.
- **CSS3** — Styling and visual presentation.
- **JavaScript (ES6+)** — Application logic and interactivity.
- **React.js** — Building reusable UI components.
- **Tailwind CSS** — Utility-first styling.
- **Create React App** — Setting up the React development environment.

## 🚀 Getting Started

Follow these steps to run the application locally.

### Prerequisites

Install the following tools before getting started:

- [Node.js and npm](https://nodejs.org/)
- [Git](https://git-scm.com/) — if you want to clone the repository.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/navnigarg14/Shopping-Cart-With-Theme-Selector.git
```

**2. Navigate to the project directory**

```bash
cd Shopping-Cart-With-Theme-Selector
```

**3. Install the dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

**5. Open the application**

The development server usually opens the application automatically. If it does not, visit:

```text
http://localhost:3000
```

The application should now be running locally.
